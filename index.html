Mostra del Projecte — NoSQLPaTi

Solució integral per a la gestió hotelera amb èmfasi en seguretat, alta disponibilitat i anàlisi.

Autors: Adrià Rodríguez i Izan Ruiz
Veure Codi a GitHub

Resum del Projecte

Problema: Sistemes fragmentats de gestió hotelera que dificulten la traçabilitat, seguretat i l'anàlisi d'ingressos.

Solució: Plataforma centralitzada per a la gestió integral (reserves, clients, facturació, check-in/out) amb interfície d'escriptori i processos automatitzats.

Gestió integral Jira · GitHub

Arquitectura i Base de Dades

Problema: Models ER complexos que poden portar a anomalies si no s'optimitzen.

Solució: Disseny ER rigorós i normalització relacional per garantir integritat i rendiment sobre PostgreSQL desplegat en Debian 12.

Disseny ER PostgreSQL Normalització

Seguretat Avançada

Problema: Dades sensibles exposades i accés sense control granular.

Solució: Arquitectura de seguretat amb SSL amb renovació automatitzada, enmascarament de dades, RBAC i triggers PL/pgSQL que eliminen automàticament dades de targetes al check-out.

SSL · Renovació RBAC Data Masking

Alta Disponibilitat i DevOps

Problema: Interrupcions i processos manuals de recuperació que impacten operacions crítiques.

Solució: Repligació entre nodes (modes actiu-actiu / actiu-passiu), balanceig i scripts automatitzats en Bash/Python agendats amb Cron per backups i restores. Dimensionament de hardware especificat per SLA.

Replicació Docker/VM Backups (Cron)

Desenvolupament Backend / App

Problema: Necessitat d'una UI d'escriptori lleugera i fiable per a recepció i gestió.

Solució: Aplicació en Python amb Tkinter per processos de front-office, login segur amb hashing bcrypt i mòduls per a la gestió completa de reserves i check-in/out.

Python · Tkinter Hashing (bcrypt)

Integracions i BI

Problema: Falta d'informes accionables i interoperabilitat amb entitats externes.

Solució: Integració amb API Mossos d'Esquadra (JSON), exportació XML de reserves i dashboard operatiu a PowerBI per anàlisi d'ingressos i KPI.

API JSON XML PowerBI

Testing

Problema: Escenaris reals de càrrega sovint no reproduïts en proves bàsiques.

Solució: Generació de dades de prova (100k reserves, 50k clients) amb suport multi-idioma i scripts de càrrega per validar integritat i rendiment abans del desplegament.

100k registres Multi-idioma
Document tècnic i manuals d'instal·lació i usuari inclosos.

NoSQLPaTi — Solució per a gestió hotelera

Plataforma integral per a reserves, check-in/out i anàlisi operativa

Autors: Adrià Rodríguez i Izan Ruiz
Veure Codi a GitHub

Resum del Projecte

Gestió integral per a establiments hotelers (Espamus+).

Problema: Operacions fragmentades i processos manuals que generen errors, pèrdues d'ingressos i mala experiència d'usuari.

Solució: Plataforma centralitzada que unifica reserves, facturació, check-in/out i informes en una interfície estable i segura, amb exportacions per a tercers i dashboards analítics.

Python PostgreSQL Jira GitHub
Projecte: Espamus+
Equip: 2 autors

Arquitectura i Base de Dades

Model ER, normalització i optimitzacions per a rendiment.

Problema: Models de dades insuficients provoquen inconsistències i consultes lentes.

Solució: Disseny ER formal, normalització fins a la forma adequada i estratègia d'indexació per a consultes crítiques; desplegament sobre Debian 12 amb PostgreSQL optimitzat.

PostgreSQL ER Design PL/pgSQL Debian 12
Índexs, particions i consultes preparades

Seguretat Avançada

Protecció i govern de dades com a prioritat.

Problema: Dades sensibles exposades i requisits de compliment normatiu.

Solució: Capa TLS (SSL) amb renovació automatitzada, estratègies de data-masking per dades sensibles, model RBAC per permisos i triggers PL/pgSQL que eliminen dades de targetes en acabar el procés de check-out.

SSL / TLS RBAC Data Masking Triggers PL/pgSQL
Hashing d'accés amb bcrypt

Alta Disponibilitat i DevOps

Disseny per continuïtat i recuperació ràpida.

Problema: Temps d'inactivitat i pèrdua de servei en pic de càrrega.

Solució: Arquitectura amb rèplica (modes actiu-actiu / actiu-passiu), balanceig de càrrega, i scripts automàtics (Bash/Python + cron) per backups i restauracions. Planificació de capacity/hardware sizing per SLA.

Docker / VM Replicació Bash / Python Automatització (cron)
Backups incrementals i restores verificats

Desenvolupament Backend/App

Aplicació d'escriptori i lògica de negoci segura.

Problema: Interfície bàsica i autenticació feble.

Solució: Aplicació en Python amb Tkinter per gestió operativa, sistema de login amb hashing (bcrypt), i mòduls de gestió de reserves i processos de check-in/out amb validacions i controls transaccionals.

Python Tkinter bcrypt
Validacions i gestió d'errors robusta

Integracions i BI

Connexions externes i visibilitat comercial.

Problema: Dades aïllades i processos de report limitats.

Solució: Integració amb APIs externes (ex. Mossos d'Esquadra via JSON), exportacions XML estructurades per proves i intercanvi, i dashboards a PowerBI per anàlisi d'ingressos i KPI operatius.

XML Export API JSON PowerBI
Informes automatitzats i connectors ETL

Testing

Dades sintètiques i proves de càrrega a escala.

Problema: Cobertura insuficient d'escenaris i volums reals.

Solució: Conjunt de dades dummy (100k reserves, 50k clients) amb suport multi-idioma, proves de rendiment i regressió per validar latència i escalabilitat abans de producció.

100k Registres Multi-idioma Stress Tests
Scripts de generació i benchmarks
Documentació tècnica i manuals d'instal·lació inclosos.
